One line. One Monday. No title, no explanation — just the review.

`main.ts` writes the winning one-line Monday review to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). The line is fixed, deterministic, and guarded: the program fails
loudly if it is not 1–200 characters or not a single line.

Winner (internal top pick; CrowLLM panel returned 0 usable verdicts — all HTTP 429):

> My Monday in one line: 9 a.m. meeting, 10 a.m. meeting about the 9 a.m. meeting, 11 a.m. regretting both.
